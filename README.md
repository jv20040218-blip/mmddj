## 三级目录

上方分类标题只有：**主线、支线、其他**。

- **主线 → 1–8／9–14／15–17 → 每章**。第一块包含序章及1至8章，原1至5合编入口仅用于旧档兼容。每章使用可展开标题，不再使用篇目选择框。雪原回忆保留在1–8其他剧情之前。
- **支线 → 国家 → 每章**。例如“支线 → 乌萨斯 → 人们我们”。
- **其他**：无国家归属的篇目、人物专题、联动和独立补充剧情，按分组展开；不重复列出已纳入主线的分章。

同级只展开一个分块或篇目，进入前仍可查看完整剧情。保留人物线预览、自由切幕、状态栏推进、结算退出和结束回执。

当前14份主线、39份支线JSON逐文件对齐。构建按源文件夹重建归属，不静默漏收新增文件。内部节点代码不作为人物姓名，交汇场景中的不同人物视角仍保留。

本版配套世界书：**明日方舟剧情模块·附加世界书_三级目录_v4**。版本、数据和卡哈希见 `release.json`。
