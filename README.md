## 开局报 undefined.map 的根因修复

旧部署把卡内世界书条目直接写成原生世界书，缺少 key/keysecondary，导致助手读取崩溃。
本版按实际酒馆字段约定转换，提供原生 data/base_worldbook.json，并同步卡内 enabled/disable。
保留主世界书重取、白底下拉框、主线三块与逐章目录、支线国家目录和乌萨斯两篇。

世界书：**明日方舟剧情模块·附加世界书_三级目录_v4_4**（2049 条）。
正常安装：更新原插件、刷新并导入本版卡，无需覆盖文件或卸载重装。
手动部署者应从 release.json 的 worldbook.path 获取原生书，通过酒馆接口导入；禁止将卡内 entries 数组直接写为原生格式。

验证：219 项测试、159 项成品检查；使用实际助手读取函数验证 2049 条，隔离执行全部 61 个开局并核对开关值。
未调用付费模型；未将隔离开局测试称为真实页面点击验收。
