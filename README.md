- 《时间啊，向前！》在素材中位于 `支线/乌萨斯/`，此前旧索引仍把它挂在支线根目录，导致「支线 → 乌萨斯」只显示一篇。

- 「其他」不再保留这一篇的根目录入口；没有成员的空分组不再显示。

- 凯尔希个人ss、精英干员、彩虹六号联动仍在「其他」，未借本次迁移改动。

## 目录结构

上方分类标题只有：**主线、支线、其他**。

- **主线 → 1–8／9–14／15–17 → 每章**。第一块包含序章及1至8章，原1至5合编入口仅用于旧档兼容。
- **支线 → 国家 → 每章**。归属由源文件夹路径重建，不按标题硬编码。
- **其他**：无国家归属的篇目、人物专题、联动和独立补充剧情。

当前 14 份主线、39 份支线 JSON 逐文件对齐；缺项或失效入口会直接构建失败。

本版配套世界书：**明日方舟剧情模块·附加世界书_三级目录_v4_2**（2049 条）。旧书 `v4_1` 可留作回退，导入新卡后以新书为准。

验证：207 项测试通过、156 项交付检查通过；21944 段原文注入比对全部一致。本次未调用付费模型。

## 升级后仍是旧目录？

先确认扩展页显示的版本为 1.6.0、数据版本为 `5e94ee293f48`，再强制刷新页面（浏览器缓存会保留旧 JSON）。导入 1.6.0 配套卡后，卡内绑定的是 `v4_2` 世界书。
