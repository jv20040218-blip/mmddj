## 本次修复

- 主线顶层为 **1–8、9–14、15–17 三个整块**。展开后在“本块剧情文件”中选择原始篇目，不再平铺各章；雪原回忆仍排在1–8其他剧情之前。
- 支线按当前原始文件夹重建国家／专题归属。**支线 → 乌萨斯 → 人们我们**，素材为 `支线/乌萨斯/人们我们.json`。
- 当前14份主线与39份支线JSON逐文件对齐，0份漏收、0个失效源入口。各国篇目数由实际文件决定，不强行补成相同数量。
- “其他剧情”不再重复列出已纳入主线的六个官方分章。旧入口和稳定路由保留用于存档恢复。
- 不再把 `ST`、`MS` 等内部代码当人名：相应路线显示梅菲斯特、米莎等素材人物名。没有明确人物的内容显示剧情片段。
- 发生逻辑句子被误识别且已由有效路线覆盖的伪入口隐藏；不同人物的交汇场景视角仍保留。
- 构建时重新对照真实源文件夹，新增未编译文件或旧路径失效会明确报错，不能静默漏收后发布。

保留上版的自由切幕、状态栏推进、结算、保存退出、结束回执、结尾原文查看和同名人物来源后缀自动匹配。
