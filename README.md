# 明日方舟剧情模块 · 1.3.0

本仓库提供酒馆扩展的剧情数据，以及配套角色卡。版本 1.3.0 加入状态栏的完整结束流程与来源角色档案自动匹配。

## 安装或更新

插件安装地址：

```
https://github.com/jv20040218-blip/mmddj
```

在酒馆的扩展管理中安装这个地址。已经安装本仓库的用户，在扩展管理中检查更新并更新，再刷新页面，无需手动覆盖文件夹。

然后下载并导入本版配套角色卡：

[下载角色卡 1.3.0（PNG，含基础世界书）](https://raw.githubusercontent.com/jv20040218-blip/mmddj/v1.3.0/cards/ark-story-v1.3.0.png)

角色卡约 15.3 MiB，剧情原文数据留在插件中。卡内包含本版基础世界书，不需要额外下载世界书文件。角色版本应显示 **1.3.0**；主世界书应为 **明日方舟剧情模块·附加世界书_结算角色档案版_v2**。如果酒馆保留了旧书绑定，请在角色编辑中选回本版书。

插件和卡必须配套更新。不要同时运行重复安装的两个数据插件，也不要同时附加旧书和新版书的同名角色状态。

## 使用

- 剧情目录按“主线章节块／支线国家 → 篇章 → 角色线”逐级展开；先看完整预览，再选择是否进入。
- 可以自由选择幕和段落，不把跳过的部分补记成已完成。
- 状态栏显示当前段与下一步；模型判断卡住时，可按“确认本段完成／推进”推进一段。
- 任意阶段均可“保存并退出当前线”。末段确认后，可“结算并结束本线”。
- 结束回执保留完成幕数、结束节点和结尾原文；可进入下一篇或回目录选其他线。下一篇按钮不自动生成回复。
- 一条线结束不等于全章完成。回忆结束会恢复原上下文；结算后继续聊天属于尾声，不重复演末段。

## 人物资料

从素材整合 191 条人物／实体资料，对应 175 个身份；5 条同角色同正文复用，新增 186 条世界书条目。来源篇章后缀区分重名资料。

进入、切幕、正常推进和恢复聊天时，按篇章与既有状态规则重新匹配。明确场景／回忆时期锚点优先于来源形态后缀；未知日期仍写“暂无”，未标定的变化节点不会被猜造。
