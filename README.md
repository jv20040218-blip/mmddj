## 开局识别与下拉框修复

- 配置启用事件现在携带实际配置，控制台也兼容无事件数据的旧通知，重新加载主世界书。
- 应用开局前重新读取当前角色的世界书绑定，避免沿用初始化时的空缓存。未找到书时明确提示，不会假装应用成功后切换开局。
- 本卡绑定接口迟到时，校验本版配套世界书存在后用于控制台；切换到其他角色后不会沿用本卡书名。

- 保留 1.6.0 的乌萨斯两篇归属；剧情正文、稳定 ID 与进度结构不变。

## 使用

已安装用户在原扩展中更新并刷新，然后导入本版新卡。无需覆盖文件或卸载重装。
本阶段控制台与剧情界面仍随卡内脚本交付，仅更新数据插件不能替换旧卡脚本。
世界书：**明日方舟剧情模块·附加世界书_三级目录_v4_3**（2049 条），新卡已绑定；旧书可留作回退。

主线 → 1–8／9–14／15–17 → 每章；支线 → 国家 → 每章；无归属专题与联动在其他。

验证：214 项测试、156 项成品检查通过。四个开局回归用例在原脚本失败、修复后通过。
剧情数据 SHA-256 与 1.6.0 一致，沿用该版 21944 段逐段原文比对结果，未调用付费模型。
浏览器工具无法确认当前网址而停止，本版未完成真实页面点击验收；不将接口检查等同于界面验收。
