## 全屏控制台与完整摘要

删除旧拦截记录/STANDBY小窗。原控制台入口直接打开全屏界面，关闭按钮或Escape仅隐藏界面，应用与剧情仍保持原状态。适应桌面与窄屏，内容可滚动。

当前剧情的“剧情摘要”和“出场立绘与状态”分别展开，两栏互不覆盖，窄屏改为上下排列。摘要按实际幕序完整显示，雪原19幕不再截成12幕；查阅摘要不把未来原文送给模型、不改变进度。
