开场继续使用酒馆当前预设，将“续写请求＋本线指导＋当前段原文＋收尾要求”作为临时用户请求交给酒馆助手 `generate`。不改API，不保存为玩家消息；开场时系统侧保留权威状态，当前原文只拼接一次。普通玩家发言继续原有流程。

取消、切聊天或超时只停止本次生成编号，迟到结果不写入聊天，失败后可重试，不自动反复请求。截止时间由90秒改为五分钟，并非固定等待；助手开场仍在完整结果返回后插入。

长聊天只读取需要的近期楼层与本插件变量，保留快照压缩。Pinia及依赖随插件同源提供。本版不启用数据库、独立聊天世界书或基准世界书防覆盖，现有聊天、世界书、Amily2设置保留。剧情数据与稳定ID不变。

维护目录另附ST 1.19.0聊天保存版本检查，保护聊天文件，与不启用的世界书隔离是不同功能。管理员安装后所有浏览器需刷新；直接调用保存接口的第三方也需携带读取时返回的 `X-Chat-Revision`。插件更新不能自行替换酒馆核心。

165项运行时及4项保存回归通过。本地1200px／390px浏览器核验同源依赖、雪原19幕首尾摘要、立绘页面，无页面错误。实际预设完整模型演出另需核验。见[维护说明](docs/发布说明_1.9.5.md)。

## 开局人物形态适配补齐

普通开局自动启用指定形态、关闭同一人物未选的旧形态，复用现有UID身份分组，不靠名字相似度合并人物。未涉及的人物与玩家身份选择保留；“构史成真”明确要求的平行世界同位体共存保留。

修正旧开局引用中的过时互斥说明、分类前缀及缺括号，避免目标条目未开启。缺失或歧义引用明确报错；世界书实际写入并回读成功后，才提示成功、提交历史并切换开场页。

在活动剧情中换开局，会先退出旧剧情再应用新形态，保留体验进度；从开局进入剧情再退出，恢复该开局的开关。剧情入口原有物理切换和回读机制保留。

119篇、849条路线、9885幕摘要及完整原文、全部开局正文保留。相对1.8.5，剧情数据和v5_0世界书逐字节不变；原有黑体16px/400与标题分层、全屏布局、五个剧情入口保留。

273项测试全部通过、零跳过，165项成品检查和最终脚本语法检查通过。61开局从全开、全关及前一开局状态共执行183次，核验1029条引用；另覆盖缺失/歧义、回读失败、玩家选择和剧情往返。

隔离本地Chrome使用完整2049条书的内存副本，实点开局17/40/49并核验实际测试宿主开关；确认回读失败不换开场页、剧情中换开局不残留旧路线，同时复测桌面/390px控制台与摘要页，无页面错误。依赖本地提供，不证明外部CDN可达，也不等于用户远程酒馆实测。

继续使用原插件更新入口，并导入配套新卡；无需卸载重装。本次未部署用户服务器、未调用模型，最后已核验服务器卡仍为1.8.3。不要重导世界书来重置已有聊天或人物状态。
