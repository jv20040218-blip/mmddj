## 结构、异步与界面优化

全插件正文统一黑体小四（16px）、常规字重400，标题按24/20/18px分层。保留自适应全屏和五个剧情入口；折叠冗长说明，优化切幕面板、摘要阅读宽度、窄屏换行与触控高度。

修复旧开场重试跨场景、切聊天后等待状态残留、迟到错误污染新聊天、历史快照与当前操作混用，以及加载失败/取消挂载后的占位与卸载问题。

移除已失效的窗口宽高/字号滑块、自动发送与回车拦截开关；主题、手动检测、世界书管理、历史和存档功能保留。静态作用域CSS替代全页字体扫描；三个构建器共享模块注册，修正失效npm入口，删除无调用私有渲染和被替代布局样式。历史素材和旧卡不删除。

119篇、849条路线、9885幕摘要及完整原文全部保留。相对1.8.4，剧情数据和v5_0世界书逐字节不变；不改人物开关规则、不重置进度，玩家摘要仍不注入模型。

265项测试全部通过、零跳过，165项成品检查和最终脚本语法检查通过。隔离本地Chrome实测完整控制台四个主页在1365px/390px下的字号与布局、明暗主题、关闭/Escape、历史只读及220幕摘要滚动，无页面错误。测试宿主本地提供依赖和图标字体；不证明外部CDN可达，也不等于用户远程酒馆实测。

继续使用原插件更新入口，并导入配套新卡；无需卸载重装。本次未部署用户服务器、未调用模型，最后已核验服务器卡仍为1.8.3。不要重导世界书来重置已有聊天或人物状态。
