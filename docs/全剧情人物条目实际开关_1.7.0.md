# 全剧情人物条目实际开关 · 1.7.0

## 行为

- 确认进入剧情、切换幕/线、正常回复推进、恢复聊天后，依当前场景关闭该人物其他状态条目并打开目标条目，实际写入世界书后读取核对。
- 进入前保存所管理条目的原开关；离开该人物所属场景后恢复无关条目，退出剧情恢复原开局，回忆退出先恢复外层剧情。
- 写入串行化，过期切线不会被迟到写入覆盖；开场等待写入核对，失败时明确报错并停止该次开场，不自动付费重试。
- 日期不明仍为暂无。优先级为回忆节点/明确场景、篇章上下文、原素材后缀、时间/事件、保守基础身份。博士性别等开局选择不由剧情擅自替换。
- 原重置按钮覆盖全部 2049 条（含剧情指导、来源人物档案），恢复开关及触发类型；退出活动剧情并清除当前注入，保存已有体验进度。

## 数据与身份适配

覆盖 119 篇、849 条线、9885 次线路场景访问；已有独立条目的匹配人物 637 个，其中 84 个具有多状态。
新增本名/代号关联 104 组、说话节点人物关联 1139 处、明确场景后缀及边界规则 125 条。
未创建虚构档案。原剧本中只有称谓、没有独立世界书条目的人物，保留对白并列在 JSON 清单的 speakers_without_independent_entry 字段。

## 验证含义

229 项测试、165 项成品检查；全量 10287480 项开关断言验证执行结果符合所选规则。
已验证龙门幼年开局 → 雪原斗士 → 退出恢复、幕间前后跳转、全部条目重置及写入失败不生成开场。
覆盖测试不等于为原素材中每个未知年代或身份边界完成了新的官方考据。保守基础身份回退不标为官方精确时期，来源不支持时不编造日期或事件。
原对白、节点、路线、世界书 UID 均保留，637 个人物是现有条目匹配范围，不将未有独立条目的称谓冒称为已开条目。

## 工程

- scripts/compile_worldbook_bindings.cjs：身份、本名/代号、篇章及节点适配；不改对白文本池。
- src/adapter/worldbook_sync.js：物理写入、开局快照、回读、串行化与恢复。
- src/adapter/index.js：生成前屏障、进入/推进/退出/重置接入。
- scripts/console_compat.cjs：原重置按钮连接完整重置，失败向上传递。
- tests/full_binding.test.js：全线全幕实际开关及完整重置回归。
- tools/verify_physical_api.cjs：实际交付卡运行时在临时未绑定书上执行真实酒馆读写 API，退出后删除临时书，不改玩家聊天、不调用模型。
