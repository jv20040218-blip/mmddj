# 1.8.0：删除小窗、全屏界面及完整逐幕摘要

发布日期：2026-11-17。原仓库main与不可变标签v1.8.0已发布，运行时提交`9baef8995c13e988045cf8bfec04b9074b968f58`，构建`8679e175bf8d`。

## 修改结果

1. 不再使用截图中的拦截记录/STANDBY悬浮小窗。原“📖 控制台开关”直接打开全屏界面，默认剧情页。关闭×和Escape仅隐藏界面，不禁用应用、不退出剧情。
2. 控制台占宿主视口全部宽高，使用100dvh适应窗口，移除旧400px高度、90vw宽度和拖拽缩放限制。内容滚动，导航和关闭入口保留。
3. 当前剧情摘要按实际ordered_scene_ids逐幕完整展示。雪原线19幕全部呈现，原先前12幕截断删除；其他全部849条线一并适配。
4. “当前剧情”下方分成“剧情摘要”和“出场立绘与状态”两栏，各自展开；窄屏上下排列。查看摘要不改变剧情进度、不向AI提前注入未来原文。

## 使用

更新原扩展并使用配套1.8.0卡，刷新页面。点击“📖 控制台开关”，在“剧情→当前剧情”展开“剧情摘要”或“出场立绘与状态”。两栏独立开关，可同时打开。关闭全屏后回到原聊天，剧情进度保持；退出剧情仍使用原“保存并退出当前线”。

插件文件与卡内控制台代码均有变化，单独更新扩展不能替代新卡。服务器代导入须按实际选中头像执行，并保留聊天指针、收藏及当前人物开关。此文档的发布本身不代表已取得本次服务器部署授权或已完成部署，部署事实见本地本版回执及总指导最新服务器版本。
