# 三级目录 1.5.0

上方分类固定为“主线、支线、其他”。主线按“主线 → 1–8、9–14、15–17 → 每章”分三级展开，各章为标题，不使用选择框。雪原回忆仍在1–8其余篇目之前。支线按“支线 → 国家 → 每章”展开；无国家归属、人物专题、联动放到其他，同层只展开一个分块或篇目。

构建模块 `scripts/catalog_layout.cjs` 每次读取当前素材文件列表，并与编译后的导航逐一匹配。当前基线为14份主线与39份支线，乌萨斯文件夹中的“人们我们.json”必须出现在乌萨斯分组。文件数不同并不自动判错，新增或失效的未编译文件应明确阻止发布；确认接入后同步相关验收基线。

六个已经纳入主线1–5的官方分章只隐藏重复目录入口，不删除路由、正文或旧存档ID。其他真实独立剧情仍保留。

`spk_` 表示素材说话人，不等于没有名字的人物；角色线命名应使用其真实姓名。`ST`、`MS` 等是节点代码，不是角色名。没有明确焦点人物时显示“独立片段”；被发生逻辑句子误识别且已由有效路线覆盖的伪入口可以隐藏。相同交汇场景的不同人物视角必须保留。

目录转换进入正式插件数据和数据版本；卡、世界书、插件数据同时按配套版本发布。只修改本地预览不能算修复交付。
