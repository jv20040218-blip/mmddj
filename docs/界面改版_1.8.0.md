# 1.8.0界面修改与验收约定

用户于2026-11-17要求删除截图中的“拦截记录 / STANDBY”悬浮小窗，入口直接打开大界面；大界面覆盖视口并自适应；雪原19幕等摘要完整呈现；当前剧情内摘要与出场立绘分成两栏，各自展开。

## 交互与布局

- 保留原“控制台开关”入口。默认不展示旧小窗，点击直接打开全屏控制台，初始展示剧情页。再次点击或使用“关闭×”与Escape关闭界面，不禁用应用、退出剧情或改变世界书。
- 外壳占宿主视口全部宽高，动态视口高度为100dvh。取消旧400px内容高度、90vw上限、拖拽定位及角落缩放；导航保留，内容区独立滚动。
- 当前剧情的目标/推进按钮保持可见且可用；下方并列“剧情摘要”“出场立绘”两个原生折叠面板，默认均折叠、可同时或独立打开。窄屏上下排列，图片使用自身容器，不覆盖摘要。
- 摘要以实际角色线ordered_scene_ids为完整幕序，逐幕使用现有摘录，缺摘录时取本幕已有说明/完成条件。无12幕或首尾采样限制，不编造原文。仅供玩家查看，不因展开预览改变进度或向模型注入未来原文。
- 无活动剧情时提供目录入口；没有出场人物时明确显示暂无；图片失败仍保留姓名与占位。

## 验收

1. 入口第一次点击后直接全屏，关闭后无STANDBY小窗；关闭不改变应用启用状态和人物开关。
2. 1366×768与390×844视口中外壳四边贴合视口，能关闭、滚动、使用导航；Escape可关闭。
3. 真实雪原路线19幕全部出现，包含第13—19幕；所有角色线摘要条数和幕序与路线一致。
4. 两栏可分别展开，打开立绘不遮挡、关闭或替换摘要；窄屏换为上下排列。
5. 配套卡/插件同版本，原书与剧情数据字节保持；真实页面验收和离线DOM验证分别记录。
