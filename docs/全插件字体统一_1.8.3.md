# 1.8.3：全插件小字提升与加粗

用户明确要求以“历史回复快照”的字号和加粗设置为基准，整个插件中小于它的文字提高到该字号，全部加粗；范围不止摘要。

## 范围与规则

参考标题的源码样式为14px、600字重。运行时若能读取到该标题，使用其实际计算样式；未打开历史页时，以14px/600作默认下限。

统一覆盖原控制台主页、世界书、剧情目录、当前剧情、摘要、立绘、历史、设置、底部导航、按钮、输入框、说明和标签；同时覆盖插件的开局界面及附加状态栏。脚本自身文档和宿主父文档均挂载处理，切页、展开和新增内容时自动处理。

小字提升到参考字号，原本更大的标题、文字和图标不缩小；字重至少达到参考加粗程度，原本更粗者保留。字体家族与Material图标字体保留，避免将图标替换为普通文字。字号提升导致固定行高不足时一并放宽行高。

处理只针对本插件拥有的根容器，不修改酒馆聊天正文、浏览器菜单或其他扩展。变化按帧合并，先读取计算样式再统一写入；监听子节点变化，避免自身样式写入触发循环扫描。页面卸载时取消监听。

## 验证

29项相关回归、165项成品检查与完整脚本语法检查通过。其中字体回归核对小字提升、较大标题保留、控制台/开局/状态栏范围、外部聊天文字不变、动态切页及监听释放。

原文库及世界书与1.8.2逐字节一致。雪原线19幕的新摘要本次只交付桌面文稿和JSON草稿，未写入运行数据；后续其他剧情完成后再统一录入。

没有调用模型，没有进行真实浏览器字体及窄屏几何验收，不能以源码/DOM回归代替用户当前页面的实际显示效果。服务器部署状态按最新回执记录，不把发布成功称为已经安装。
